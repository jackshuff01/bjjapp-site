Website privacy

This notice covers this public website, bjjapp.uk. It does not cover the signed-in app at app.bjjapp.uk.

What this site collects

Nothing directly. It has no accounts, forms, cookies, analytics or advertising trackers, and it loads no third-party fonts or scripts.

Hosting

The site is hosted on GitHub Pages. GitHub may log visitors' IP addresses for security and to keep the service running. See the GitHub Pages data collection note.

If you email us

We use your email address and what you send only to reply and to help set up your gym. Ask us at any time to see or delete it.
